# ASN Web Example

Этот пример демонстрирует использование ASN WGPU в веб-среде с помощью WebAssembly. Проект включает современный пользовательский интерфейс с улучшенной обработкой ошибок, индикаторами состояния и демонстрацией различных возможностей WASM.

## ✨ Особенности

- 🚀 **Быстрая инициализация** - автоматическая загрузка и инициализация WASM модуля
- 🎨 **Современный UI** - красивый интерфейс с индикаторами состояния
- 🔧 **Улучшенная обработка ошибок** - детальная информация об ошибках с временными метками
- 📊 **Демонстрация возможностей** - тесты производительности, асинхронные операции
- 🛠️ **Умные скрипты** - автоматическая проверка зависимостей и портов

## 🚀 Быстрый старт

```bash
# Переход в папку примера
cd examples/ex_web

# Автоматическая сборка и запуск
./run.sh
```

Скрипт автоматически:
- Проверит и установит необходимые зависимости
- Соберет проект для WASM
- Найдет свободный порт
- Запустит HTTP сервер
- Откроет браузер

## 🔨 Сборка

### Автоматическая сборка
```bash
./build.sh
```

### Ручная сборка
```bash
# Установка wasm32 target (если не установлен)
rustup target add wasm32-unknown-unknown

# Установка wasm-pack (если не установлен)
cargo install wasm-pack

# Сборка
wasm-pack build --target web
```

## 🌐 Запуск

### Автоматический запуск
```bash
./run.sh
```

### Ручной запуск
```bash
# После сборки
python3 -m http.server 8091

# Откройте http://localhost:8091 в браузере
```

## 🧹 Очистка

### Автоматическая очистка
```bash
./clean.sh
```

Скрипт автоматически:
- Удаляет директорию `target/`
- Удаляет директорию `pkg/`

## 🎮 Функции и возможности

### Основные функции
- `init_web_app()` - инициализация веб-приложения с логированием
- `greet(name)` - персонализированное приветствие
- `get_version()` - получение версии приложения

### Демонстрационные функции
- `get_system_info()` - информация о системе и платформе
- `calculate_fibonacci(n)` - тест производительности вычислений
- `get_memory_usage()` - информация об использовании памяти
- `test_async_operation()` - демонстрация асинхронных операций

## 🧪 Тестирование

Откройте приложение в браузере и используйте кнопки для тестирования:

### Основные функции
1. **Инициализировать приложение** - запускает `init_web_app()`
2. **Получить версию** - вызывает `get_version()`
3. **Приветствие** - вызывает `greet()` с именем "Пользователь"

### Демонстрация возможностей
1. **Информация о системе** - показывает системную информацию
2. **Тест производительности** - вычисляет 40-е число Фибоначчи
3. **Использование памяти** - показывает примерное использование памяти
4. **Асинхронная операция** - демонстрирует работу с Promise

## 🛠️ Устранение неполадок

### Проблемы со сборкой
```bash
# Очистка и пересборка
cargo clean
./build.sh

# Проверка установки wasm32 target
rustup target list --installed | grep wasm32-unknown-unknown
```

### Проблемы с запуском
```bash
# Проверка доступности порта
lsof -i :8091

# Запуск на другом порту
python3 -m http.server 8092
```

### Ошибки WASM
- **"unreachable"** - обычно означает использование несовместимых с WASM функций
- **"Module not found"** - убедитесь, что папка `pkg/` существует после сборки
- **CORS ошибки** - всегда используйте HTTP сервер, не открывайте файл напрямую

### Отладка
- Откройте Developer Tools (F12) для просмотра консоли
- Проверьте Network tab для загрузки WASM файлов
- Используйте встроенное логирование в приложении

## 🔧 Разработка

### Добавление новых функций
1. Добавьте функцию в `src/lib.rs` с атрибутом `#[wasm_bindgen]`
2. Импортируйте функцию в `index.html`
3. Создайте обработчик в JavaScript
4. Добавьте кнопку в HTML

### Изменение UI
- Основные стили находятся в `<style>` секции `index.html`
- Логика интерфейса в `<script>` секции
- Используйте классы `.error`, `.success`, `.info` для сообщений
