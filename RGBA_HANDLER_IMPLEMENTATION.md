# Реализация RgbaHandler в модуле wgpu_map

## Обзор

Был успешно создан и интегрирован класс `RgbaHandler` в модуль `wgpu_map` для инициализации и обработки RGBA-массивов.

## Что было реализовано

### 1. Основной класс RgbaHandler

**Файл:** `modules/asn-wgpu/src/wgpu_components/wgpu_map/rgba_handler.rs`

Класс предоставляет следующие возможности:

#### Конструкторы
- `new(width, height)` - создание нового обработчика с указанными размерами
- `from_rgba(data, width, height)` - создание из существующих RGBA-данных

#### Манипуляция пикселями
- `set_pixel(x, y, r, g, b, a)` - установка пикселя по координатам
- `get_pixel(x, y)` - получение цвета пикселя
- `fill(r, g, b, a)` - заполнение всей области цветом

#### Создание эффектов
- `create_gradient(start_color, end_color)` - создание линейного градиента

#### Работа с текстурами
- `create_texture(device, queue, label)` - создание WGPU текстуры из данных

#### Управление данными
- `update_data(new_data)` - обновление всех данных
- `data()` - доступ к данным только для чтения
- `data_mut()` - мутабельный доступ к данным
- `dimensions()` - получение размеров
- `resize(width, height)` - изменение размера
- `clone()` - создание копии

## Использование

### Базовое использование

```rust
use asn_wgpu::RgbaHandler;

// Создание обработчика
let mut handler = RgbaHandler::new(256, 256);

// Заполнение цветом
handler.fill(0, 0, 255, 255); // Синий цвет

// Установка пикселя
handler.set_pixel(100, 100, 255, 0, 0, 255).unwrap();

// Создание градиента
handler.create_gradient((255, 0, 0, 255), (0, 0, 255, 255));
```

### Создание текстур

```rust
// Создание текстуры из данных
let texture = handler.create_texture(&device, &queue, "my_texture").unwrap();
```

### Работа с существующими данными

```rust
let rgba_data = vec![255u8; 100 * 100 * 4];
let handler = RgbaHandler::from_rgba(&rgba_data, 100, 100).unwrap();
```
